# Forge Visual Studio

Forge Visual Studio is a visual-workshop project exploring an approachable interface for AI-assisted image creation and export.

## Project direction

- A focused interface for entering image-generation requests
- Previewing generated visual results
- Exporting artwork as PNG
- Keeping provider credentials and sensitive configuration on the server side
- Building a workflow that can be extended as the project matures

## Development principles

The project is intended to keep the user-facing workflow simple while separating the interface from provider-side operations. Public materials describe the project at a high level and do not expose private source code, credentials, or deployment configuration.

## Status

**Project preview — availability is not guaranteed.** The actual operation of image generation depends on deployment and provider configuration. Do not assume that generation or export features are live in a public production environment unless they have been tested there.
